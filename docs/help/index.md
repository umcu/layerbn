# Help

<div class="grid cards" markdown>

-   :material-alert-circle-outline:{ .lg } [**Error messages**](troubleshooting.md)

    Every message layerbn gives, what it means and what to change. Also: an arc you expected
    is missing, the network is almost empty, the sweep is flat.

-   :material-github:{ .lg } [**Report a problem**](https://github.com/umcu/layerbn/issues)

    Open an issue on GitHub. Include the output of `layerbn --traceback check my-study` and
    your `settings.yml`, never your data.

</div>

!!! tip "Most problems are found by a check"

    `layerbn check my-study` reads everything without fitting a model and says in plain
    language what is wrong and where.
