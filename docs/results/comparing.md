# Comparing networks

When you fit [several networks](../guide/networks.md), for example with and without a layer,
the report puts the stability of every arc side by side.

| You see | It may mean |
| --- | --- |
| An arc stable in both networks | It does not depend on the layer you left out. |
| An arc only without the layer, or a variable with new parents | The layer explains it, for example as a mediator or a common cause. |
| A dash | The arc never appeared, or it is impossible because a variable is left out. |

!!! note "Descriptive only"

    There is no test for a difference in stability between networks.
